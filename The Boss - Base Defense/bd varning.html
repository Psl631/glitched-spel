⚠️ MEDICINSK VARNING: Spelet innehåller intensiva stroboskopljus, skakande effekter och plötsliga högfrekventa ljud. Rekommenderas ej för personer med epilepsi eller liknande sensorisk känslighet.

🧠 SENSORISK PROFIL

  • SYN: Kraftiga färgväxlingar (vitt/lila) vid skott och slumpmässiga Kamek-attacker. Skärmen skakar vid skada.
  • HÖRSEL: Hög techno-musik, glaskross och varningssirener. Stäng av musiken genom att klicka på bandspelaren (boombox) i hörnet eller tryck [M].
  • KÄNSEL: Handkontroller ger fysiska vibrationer vid explosioner och träffar.
  • KOGNITION: Högt tempo. Kräver snabb sortering av mål (skjut fiender, ignorera fällor).
  • NÖDSTOPP: Tryck [S] för att omedelbart tysta alla stroboskopeffekter.

Skjut ALDRIG på radioaktiva tecken. En träff orsakar omedelbar detonation och GAME OVER.

🧙‍♂️ ANTI-CHEAT ÖVERVAKNING

Operatör PSL631 (Kamek) övervakar terminalen i realtid. Systemet detekterar automatiskt: Turbo-klick, makron och otillåtna script. Vid fusk låses terminalen omedelbart (Lockdown) och dina poäng nollställs. "Nyehehehe! Jag ser allt!"

• 0 liv = Systemkrasch och Game Over.
