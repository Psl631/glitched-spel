## 🚀 Quick Start (3 Steps)

### Step 1: Include Translation Library
Add to your `index.html` (in `<head>` section):
```html
<script src="translations.js"></script>
```

### Step 2: Replace Swedish Text
**Before:**
```javascript
showToast("🔈 RADIO OFF", "#888");
```

**After:**
```javascript
showToast(t('radio_off'), "#888");
```

### Step 3: Test
Open game in browser → Language automatically matches your browser settings!

## 🔍 Translation Key Examples

### Simple Keys (Static Text)
```javascript
t('score')           // Returns: "SCORE"
t('start_game')      // Returns: "START GAME"
t('instructions')    // Returns: "INSTRUCTIONS"
```

### Function Keys (Dynamic Text)
```javascript
t('good_luck_msg', 'Alice')
// Returns: "GOOD LUCK, ALICE!"

t('emergency_ammo_used', 2)
// Returns: "🚨 EMERGENCY AMMO USED! (2 left)"
```

## ⚡ Common Implementation Patterns

### Pattern 1: UI Label
```html
<span id="score-label"></span>
<script>
    document.getElementById('score-label').textContent = t('score');
</script>
```

### Pattern 2: Toast Message
```javascript
showToast(t('invincible'), "gold");
```

### Pattern 3: Wave Display
```javascript
if (waveEl) waveEl.innerText = t('wave') + " " + wave;
```

### Pattern 4: Conditional Rating
```javascript
if (score < 1000) rating = t('terrible');
else if (score < 3000) rating = t('poor');
else rating = t('great');
```

## 🔧 Troubleshooting Quick Links

| Issue | Solution |
|-------|----------|
| Text shows `[key]` | Key not found - check spelling in translations.js |
| Language not changing | Clear browser cache, check localStorage |
| Script not loading | Verify path: `<script src="translations.js"></script>` |
| Functions not available | Ensure script loads before using t(), getCurrentLanguage(), etc. |
