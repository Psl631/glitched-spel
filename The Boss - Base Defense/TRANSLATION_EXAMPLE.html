🌐 Base Defense Ultra - Translation System

This page demonstrates how to implement the multi-language translation system.

🗣️ Select Language

Quick Integration Steps

  1. Include the library:
    <script src="translations.js"></script>
  2. Use the translation function:
    t('score') returns the localized "SCORE" text
  3. For dynamic content with parameters:
    t('emergency_ammo_used', 2) returns localized text with count
  4. Let players change language:
    setLanguage('da') switches to Danish and reloads

Common Use Cases

HTML Element (Static Text)

<div class="stat-box">
    <span id="score-label"></span>: <span id="score">0</span>
</div>

<script>
    document.getElementById('score-label').textContent = t('score');
</script>

JavaScript Toast Message

// Before translation:
showToast("🌟 ODÖDLIG! (7 SEK)", "gold");

// After translation:
showToast(t('invincible'), "gold");

Dynamic Content with Parameters

// Display: "🚨 NÖDAMMO ANVÄND! (2 kvar)" in Swedish
// Display: "🚨 EMERGENCY AMMO USED! (2 left)" in English
showToast(t('emergency_ammo_used', 2), "#ffcc00");

Conditional Text

if (finalScore < 1000) {
    rating = t('terrible');
} else if (finalScore < 3000) {
    rating = t('poor');
} else {
    rating = t('great');
}

How It Works

  1. Browser Detection: Game detects browser language on first load
  2. LocalStorage: Language choice saved for future visits
  3. Function Call: t(key, ...params) returns translated string
  4. Language Switch: setLanguage('no') saves choice and reloads page
  5. Parameter Support: Function-type keys accept arguments for dynamic content

All Translation Keys

View translations.js for complete list of available translation keys. Common ones include:

UI: score, mag, wave, start_game, instructions, settings
Messages: good_luck_msg, wave_complete, mission_failed
Warnings: low_battery, offline_warning, performance_drop
Ratings: terrible, poor, average, good, great, excellent, legendary

Testing Guide

In browser console:

getCurrentLanguage()           // Returns: 'en'
setLanguage('da')             // Switch to Danish
t('score')                    // Returns: 'SCORE' (English) or 'SCORE' (Danish)
getAvailableLanguages()       // Lists all available languages
t('good_luck_msg', 'Alice')   // Returns: 'GOOD LUCK, ALICE!'
